# Web2APK Studio

Convert any website into a feature-rich native Android WebView app and manage your web projects.

## Deployment on Vercel & GitHub

1. Push this repository to your GitHub repository.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel will automatically detect the Node.js backend (`server.js`) and static frontend (`public/index.html`) using `vercel.json`.
4. Deploy with one click!
